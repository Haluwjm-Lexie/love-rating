# Love Rating ♡

12 个恋爱现实选择题，发现你的趣味恋爱类型。使用 HTML、CSS 与原生 JavaScript 制作，适配手机与电脑。

## V1.2

- 四种趣味类型：心动优先派、关系观察员、温柔谈判家、人生掌舵人；增加四个方面的选择倾向。
- 根据本次答案生成优势、提醒与对应主题的现实解读。
- 十二条可展开的现实指南，涵盖向上社交、礼物、共同创业、异地机会、消费差距、潜力与等待、隐形劳动、资源与话语权、沉没成本、关系确定性、家庭与退路、自己的人生。
- 上一题、随机选项顺序、防重复点击计分。
- 下载 PNG 结果卡；分享或复制包含结果与网址的文案。
- 无 CDN、注册、API 密钥、统计脚本或外部字体。回答自动保存在当前浏览器 localStorage；支持手动保存、刷新后继续、首页清除进度。清除浏览器数据、更换浏览器或域名后不可同步。公共设备建议测完后回首页清除。

这是规则驱动的趣味自我探索，不是经过验证的心理量表，不提供人格、依恋类型或心理诊断。类型不代表高低等级。题目与小贴士为原创一般性表达，没有声称专业知识库背书。

## 本地使用

解压后双击 `index.html` 即可。分享功能会根据浏览器能力使用系统分享、剪贴板或手动复制；本地打开不包含在线网址。

## 发布到 GitHub Pages（无需安装开发环境）

1. 登录 GitHub，新建公开仓库，名称建议 `love-rating`。不要上传私人材料。
2. 进入仓库，点 **Add file → Upload files**。
3. 上传本目录中的 `index.html`、`style.css`、`quiz.js`、`app.js`、`.nojekyll`、`README.md`。请确保 `index.html` 直接位于仓库根目录，不要多套一层文件夹。
4. 点击 **Commit changes** 保存。
5. 打开 **Settings → Pages**。
6. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
7. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
8. 等 GitHub 完成构建。Pages 设置页显示的访问地址才是确认的线上地址；首次发布可能需等待几分钟。

若账号为 `Haluwjm-Lexie`，仓库名为 `love-rating`，通常地址为 `https://haluwjm-lexie.github.io/love-rating/`。这是预期地址，发布前不代表已上线。

后续更新相同文件并提交即可重新发布。所有资源采用相对路径，支持 Pages 的仓库子路径。
